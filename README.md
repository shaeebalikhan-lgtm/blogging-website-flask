# Blogging Website (Flask)

A dynamic blogging platform developed using Flask that allows users to create, edit, and manage blog posts. The application includes user authentication, secure session handling, and database integration for efficient content management.

## Features
- User registration and login
- Create, edit, and delete blog posts (CRUD)
- Secure session management
- Form validation
- Responsive design
- Database storage using SQLite/MySQL

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite / MySQL
